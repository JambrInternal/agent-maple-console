# Design System & Branding

**Agent Maple** reflects a premium, industrial, and high-confidence aesthetic.

## 1. Color Palette

### Primary
- **Burnt Orange (`#C26A2E`)**: Used for primary actions (text, borders) and the "Maple" identity.
- **Light Orange (`#FFF7ED`)**: Used for subtle backgrounds and active state tints.

### Secondary
- **Deep Navy Blue (`#001F3F`)**: Used for headers, the sidebar header, and strong interactive elements (buttons).
- **White (`#FFFFFF`)**: Used for card backgrounds and high-contrast text on Navy.

### Neutral
- **Background (`#F9FAFB`)**: Flat light grey/off-white for the main app canvas.

## 2. Typography
- **Font Family**: `Inter` (System UI fallback).
- **Weights**: `400` (Body), `500` (Labels), `600/700` (Headings/Active States).

## 3. UI Elements

### Sidebar Navigation
We use the **"Minimalist Industrial"** style (Option C):
- **Active State**: Transparent background.
- **Text**: Bold Navy Blue (`#001F3F`).
- **Indicator**: A distinct Burnt Orange **dot** (6px circle) floating to the right of the active item.

### Shapes & Spacing
- **Border Radius**: `4px` (`0.25rem`) - Sharp, professional, precise.
- **Cards**: Flat white backgrounds with subtle shadows (`box-shadow: 0 1px 2px rgba(0,0,0,0.05)`).

## 4. Logo Assets
- **Full Wordmark**: Used in the expanded Sidebar header (White text on Navy).
- **Icon Mark**: Used in the collapsed Sidebar (White Maple Leaf on Navy).
