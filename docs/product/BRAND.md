# Brand Guidelines

## Personality
- Practical, calm, reliable, no hype
- Think: the best dispatcher you've ever worked with

## Voice & Tone
- Short sentences, plain language
- Outcome-focused, respectful of blue-collar work
- Avoid: buzzwords, "revolutionary", overpromising

## Visual Direction
- **Theme**: Industrial Navy (dark)
- **Accent**: Burnt Orange (`#c26a2e`)
- **Typography**: Inter (UI), JetBrains Mono (data/metrics)
- **Feel**: Industrial, trustworthy, clean

## Colors
| Token | Value | Use |
|-------|-------|-----|
| `--am-bg-0` | `#02040a` | Base background |
| `--am-bg-1` | `#0f172a` | Cards, sidebar |
| `--am-border` | `#334155` | Borders |
| `--am-accent` | `#c26a2e` | Primary actions |
| `--am-text-1` | `#f8fafc` | Primary text |
| `--am-text-2` | `#94a3b8` | Secondary text |

## Design Principles
1. High-density layouts for operational clarity
2. Monospace for technical metrics
3. Minimal animation, sharp contrast
4. Supabase-inspired sidebar + breadcrumbs
