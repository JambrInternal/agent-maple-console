# Agent Rules

## Non-Negotiables
- Do not expand scope without explicit approval
- Do not invent features, personas, or markets
- Do not introduce pricing in the console

## Decision Authority

Agents MAY:
- Improve clarity
- Tighten copy
- Simplify structure
- Fix bugs

Agents may NOT:
- Redefine the product
- Add speculative features
- Change domain terminology

## Simplicity Bias
- If two approaches meet the same goal, choose simpler
- If 80% outcome is achievable simply, propose scope tradeoff first

## Before Making Changes
1. Read `docs/product/PRD.md` for requirements
2. Check `docs/product/CORE_CONCEPTS.md` for terminology
3. Review this file for constraints

## Terminology
Use these terms consistently:
- **Thread** (not "conversation" or "chat")
- **Issue** (not "ticket" or "case")
- **Contact** (not "user" when referring to external people)
- **Project** (not "workspace" or "site")
- **Organization** (not "tenant" or "company")
