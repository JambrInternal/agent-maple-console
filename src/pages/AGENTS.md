# src/pages/ — Agent Rules

Route-level page components.

- One directory per route page: `src/pages/<Page>/<Page>.tsx` (e.g., `src/pages/Knowledge/Knowledge.tsx`)
- Page tests are colocated with page files: `src/pages/<Page>/<Page>.test.tsx`
- Pages compose feature components — keep page files thin
- Naming: `PascalCase` for both directory and page file
- Routes are defined in `src/app/AppRoutes.tsx`

See `/AGENTS.md` for project-wide rules.
