# Copy Rules

## Voice
- Short sentences
- Plain language
- Outcome-focused
- Respectful of blue-collar work

## Avoid
- Buzzwords ("revolutionary", "next-gen", "AI-powered")
- Overpromising
- Technical jargon in user-facing copy

## UI Copy Guidelines

### Buttons
- Use verbs: "Save", "Create Issue", "Export Report"
- Be specific: "Launch New Project" not "Add"

### Empty States
- Explain what will appear here
- Provide a clear action

### Error Messages
- Say what went wrong
- Say how to fix it
- No blame language

### Status Labels
- Use: Done, Open, Waiting, Needs Response
- Avoid: Pending, In Progress, Active

## Review Checklist
- Would a trades owner understand this instantly?
- Is this clearer than before?
- Does every word earn its place?
